## 🌟 모바일 시그니처 6대 아티팩트 (6 Mobile Signatures)

1. **📱 iOS 18 Dynamic Island Morph**: 터치 탭 시 부드러운 스프링 물리로 미디어 플레이어로 모핑하며 스마트폰 햅틱 진동 피드백 제공.
2. **📜 Mobile Wax Seal Letter Opener**: 붉은 왁스 인장을 누르면 편지봉투가 열리고 황실 비밀 칙서가 스크롤 업되는 엔틱 모바일 인터랙션.
3. **🎛️ Web Audio Haptic Drum Pads**: 외부 MP3 없이 Web Audio API로 킥/스네어/하이햇 비트를 합성하고 스마트폰 모터를 두드리는 비트 연주기.
4. **🪙 Mobile Touch Gold Scratch Lottery**: 모바일 터치 제스처(`touchmove`, `destination-out`)에 최적화된 24K 골드 복권 스크래치 엔진.
5. **⚡ Linear Mobile 1px Laser & Gesture Bottom Sheet**: 손가락 드래그로 여닫히는 네이티브급 스프링 바텀시트와 1px 서브픽셀 레이저 카드.
6. **💎 Apple Vision Frosted Floating Tabbar**: 반투명 아크릴 글래스모피즘과 터치 햅틱 반응을 갖춘 모바일 플로팅 하단 탭바.
