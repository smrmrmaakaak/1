## 🚀 빠른 시작 (Quick Start)

### 1. 로컬에서 즉시 실행
```bash
# 저장소 클론
git clone https://github.com/smrmrmaakaak/1.git
cd 1/projects/smr-original-ui-suite

# 로컬 서버 구동
python -m http.server 5700
# 브라우저에서 http://localhost:5700 접속
```

### 2. 컴포넌트 1초 복사 & 붙여넣기
- 브라우저(`http://localhost:5700`)에서 원하는 컴포넌트 우측 상단의 **`[💻 코드 복사]`** 버튼을 클릭하면 HTML, CSS, JavaScript를 즉시 복사할 수 있습니다.
