 🌟 스타듀밸리 모바일(갤럭시 Z 플립 3) 모드 & 리텍 현장 15분 마스터 대본
================================================================================

[현장 준비물]
1. 본인 노트북 + C to C USB 케이블 (노트북과 스마트폰 연결용)
2. 스타듀밸리 모드킷 폴더 (현재 노트북에 세팅된 이 폴더)

--------------------------------------------------------------------------------
 ⏱️ [현장 15분 타임라인 & 멘트 가이드]
--------------------------------------------------------------------------------

[00분~02분] 가벼운 인사 및 사전 체크
• 멘트: "안녕하세요! 오늘 Z 플립에 모드랑 예쁜 리텍 완벽하게 적용해서 바로 게임하실 수 있게 해드릴게요. 먼저 정품 스타듀밸리 앱이 깔려있으신가요?"
• 행동 체크:
  1. 의뢰인 폰에 '구글 플레이스토어 정품 스타듀밸리' 설치 확인.
  2. 게임을 한 번 켜서 새 게임 생성(또는 로딩) 화면까지 들어갔다가 종료.
     (이걸 해야 폰 내부에 기본 게임 데이터 폴더가 생성됩니다.)

--------------------------------------------------------------------------------

[02분~05분] 노트북 USB 연결 및 파일 복사
• 멘트: "제가 노트북에 필수 프로그램이랑 인기 리텍 모드들을 오류 없이 싹 정리해왔어요. 폰에 바로 꽂아서 옮겨드릴게요!"
• 행동:
  1. C to C 케이블로 의뢰인 Z 플립 3을 노트북에 연결.
  2. 폰 화면에 뜨는 [휴대전화 데이터 접근 허용] -> [허용] 누르기.
  3. 노트북 바탕화면/폴더의 [USB_원클릭_전송_도우미.bat] 더블 클릭!
  4. 열린 창에서 [1] 폰_복사용_설치패키지 안의 파일들을 폰의 [Download] 폴더로 통째로 드래그 복사.

--------------------------------------------------------------------------------

[05분~10분] SMAPI(모드 구동기) 설치
• 멘트: "스타듀밸리 모드를 돌리려면 SMAPI라는 특수 런처가 필요해요. 요것만 깔아주면 끝납니다."
• 행동:
  1. 의뢰인 폰의 [내 파일] 앱 -> [다운로드(Download)] 폴더 진입.
  2. 복사해 둔 SMAPI.Launcher.apk 터치하여 설치 (출처 허용).
  3. 설치된 **SMAPI Launcher** 앱 실행.
  4. 앱 화면에서 [Install SMAPI From Zip] 버튼 터치.
  5. 다운로드 폴더의 SMAPI.zip 파일 선택 -> 5초 만에 설치 완료!

--------------------------------------------------------------------------------

[10분~13분] 모드 및 리텍 적용하기
• 멘트: "이제 마지막으로 예쁜 초상화, 건물 외관, 편의성 모드를 적용할게요!"
• 행동:
  1. 복사해 둔 02_Mods_모드폴더 안의 모드들을 아래 경로의 Mods 폴더 안으로 이동.
     * 경로: 내장 메모리 > Android > data > abc.smapi.gameloader > files > Mods
       (또는 SMAPI 런처 앱 내의 Mod Manager 기능 이용)
  2. 필수 모드 확인:
     - ContentPatcher (리텍 구동 엔진)
     - UIInfoSuite2 (작물 수확일, NPC 위치, 호감도 표시)
     - SkipFishingMinigame (초보자 필수 낚시 이지 모드)
     - [리텍] 고화질_미형_초상화_Pack (외모 업그레이드)
     - [리텍] 파스텔_중세풍_건물_외관
     - [리텍] 큐티_반려동물_가축_리텍

--------------------------------------------------------------------------------

[13분~15분] 최종 구동 확인 & 3만원 정산 타임! 💰
• 멘트: "자, 이제 일반 스타듀밸리 아이콘 말고, 새로 생긴 [SMAPI Stardew Valley] 아이콘으로 실행하시면 됩니다. 한번 켜보실래요?"
• 화면 확인:
  - NPC 대화창 열어서 초상화가 예쁘게 바뀌었는지 확인!
  - 인벤토리 열어서 UI Info Suite 아이콘이 뜨는지 확인!
• 마무리 멘트: "완벽하게 잘 적용됐네요! 혹시 나중에 다른 리텍 넣고 싶으시면 아까 그 Mods 폴더에 폴더째로 넣으시기만 하면 됩니다."
• -> 카페 음료 마시며 기분 좋게 3만원 수령 완료! 🎉

--------------------------------------------------------------------------------
 🚨 현장 돌발 상황 긴급 대처법 (FAQ)
--------------------------------------------------------------------------------
Q1. 폰에 연결했는데 노트북에서 폰 내부 저장소가 안 보여요!
 -> 폰 화면 잠금을 해제하고, 상단 알림창을 내려서 USB 연결 설정을 [파일 전송 / MTP]로 변경하면 바로 뜹니다.

Q2. 초상화 리텍이 안 바뀌어요!
 -> Mods/모드폴더/manifest.json 구조인지 확인하세요! (폴더 안에 또 폴더가 있는 2중 폴더면 인식이 안 됩니다.)

Q3. 게임이 켜지다가 튕겨요!
 -> Content Patcher 버전이 SMAPI 버전과 호환되는지 확인 (제가 세팅해 둔 패키지는 100% 호환 버전입니다).
